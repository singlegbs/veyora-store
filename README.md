## Configuration

`products.js` holds sample product data, the Paystack public key, and public Supabase configuration. The Paystack key currently uses live mode; do not enter payment details during testing. Live payment success depends on Paystack account approval. Never put a Paystack secret key or Supabase service-role key in this public repository.
